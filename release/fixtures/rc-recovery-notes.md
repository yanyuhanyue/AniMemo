## 📦 安装 (Installation)

- `install.animemo.cc` 仅提供引导与安装体验，GitHub Release 是唯一发行权威。
- 可显式选择 GitHub 或 Official Mirror 运输；不会静默跨源回退。
- Portable/local-bundle 仅在离线信任引导获得独立授权后启用。
