# v1.4 第一批：札记主题扩展

后续进度见 [手账主题与历史版本清理](v1.4-journal-themes.md)；本文保留当批交付证据。

这是 alpha.2 的历史交付记录。当前 alpha.3 已继续实现模板、CSS 与资源，见 [主题模板交付](v1.4-theme-templates.md) 和 [当前路线](refactor-next-steps.md)。

2026-10-09，源码版本 `1.4.0-alpha.2`。这是 v1.4 的首批开发交付，尚非完整 v1.4 或正式发行。

- 默认札记保留用户确认过的海报、彩色作品标签、灰色可见范围和手机留白；已删除之前的多套试用方案。
- 新增声明式 `theme.notes` 和官方示例「樱色信笺」1.0.0，复用包身份、安装、启停、版本切换和故障隔离。
- 「札记 → 札记外观」提供预览、应用和恢复默认。个人选择在数据库保存，只影响自己的札记及其阅读/编辑窗口。
- 核心保留布局、控件、危险操作和登录/后台页面；主题无脚本、CSS、资源 URL 或数据访问。
- 迁移 023 保存个人选择，正常升级保留；完整实例恢复停用扩展并清除选择。主题缺失时采用内置外观，不影响记录与导出。
- 宿主插件 API 增至 3，保留 API 1–2 转换器。安装新版不自动启用，主题清单变动需递增包版本，旧宿主明确拒绝新能力。

具体入口、打包、兼容与恢复说明见 [札记主题](themes.md)。

## 升级时发现的问题

首个 `alpha.1` 候选在 RC4 实例上暴露随附 TXT 包身份冲突：协议包调整引起 WASM 字节变化，却仍使用 1.1.1，核心正确拒绝覆盖旧包，但主题随附注册也被中止。原账号和记忆内容未受影响。该候选不作为交接镜像。

修正版 `alpha.2` 将重编译的 TXT 包递增为 1.1.2，保留旧包身份和管理员原先启用的版本；不放宽同版本不可变规则。容器验收新增旧镜像升级用例，核对旧转换器仍可执行、新主题正常注册，避免只测全新安装或同镜像更新。

## 当前验证

前端/API 静态检查、18 项 Node 检查与 Go 单元通过。真实 PostgreSQL 验证个人隔离、禁用和失效版本拒绝、恢复默认、独立版本切换、卸载清理、官方身份与准确 Core 绑定、损坏主题隔离及原 TXT 转换流程。浏览器使用真实接口，验证安装/启用、预览取消、应用持久化、阅读和编辑、停用回退、退出与切号；开发环境主题与默认札记共 8 次 axe 扫描、最终容器主题另 5 次扫描均无检出，0 页面异常。

云端 `stage3-review` 已升级到 `1.4.0-alpha.2`，app/worker/db healthy，doctor PASS。原 10 个账号、14 条作品记录、6 篇札记及观看、图片、收藏、年度和成就等 13 张表，升级前后内容摘要一致；浏览器验收随后只新增明确标注的合成账号与札记。原 TXT 1.1.1 的启用状态已恢复，樱色信笺已启用供用户自行选择，原账号仍使用默认纸页。

本轮 Docker vfs 缓存曾耗尽空间，导致一次测试副本和一次实例更新失败；更新工具自动恢复原实例。确认缓存属于本轮构建后清理可回收缓存，可用空间恢复到约 15 GiB；未清理数据卷、备份或镜像。跨版本测试完成后立即移除自己的临时实例，减少闲置容器占用。

完整容器回归及对应证据见 [验收记录](verification.md)。VM、25 分钟负载、Safari 与外部服务正式凭据联调未执行。
