# v1.4 第一批：札记主题扩展

2026-10-09，源码版本 `1.4.0-alpha.2`。这是 v1.4 的首批开发交付，尚非完整 v1.4 或正式发行。

- 默认札记保留用户确认过的海报、彩色作品标签、灰色可见范围和手机留白；已删除之前的多套试用方案。
- 新增声明式 `theme.notes` 和官方示例「樱色信笺」1.0.0，复用包身份、安装、启停、版本切换和故障隔离。
- 「札记 → 札记外观」提供预览、应用和恢复默认。个人选择在数据库保存，只影响自己的札记及其阅读/编辑窗口。
- 核心保留布局、控件、危险操作和登录/后台页面；主题无脚本、CSS、资源 URL 或数据访问。
- 迁移 023 保存个人选择，正常升级保留；完整实例恢复停用扩展并清除选择。主题缺失时采用内置外观，不影响记录与导出。
- 宿主插件 API 增至 3，保留 API 1–2 转换器。安装新版不自动启用，主题清单变动需递增包版本，旧宿主明确拒绝新能力。

具体入口、打包、兼容与恢复说明见 [札记主题](themes.md)。

## 当前验证

前端/API 静态检查通过。真实 PostgreSQL 验证个人隔离、禁用和失效版本拒绝、恢复默认、独立版本切换、卸载清理、官方身份与准确 Core 绑定、损坏主题隔离及原 TXT 转换流程。浏览器使用真实接口，验证安装/启用、预览取消、应用持久化、阅读和编辑、停用回退、退出与切号；桌面和 390/320 px 共 5 次 axe 扫描无检出，0 页面异常。

容器、验收镜像和 GitHub 交接结果在完成后追加到 [验收记录](verification.md)，当前不据源码测试宣称它们已经完成。
