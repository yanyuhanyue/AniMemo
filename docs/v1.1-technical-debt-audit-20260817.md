## Frozen contract correction

`FROZEN_CONTRACT_REVIEW_REQUIRED` was raised for TD-005 and is now closed by an
explicit correction and re-freeze:

- `verify_tls` was removed from runtime, management schema, validator, tests,
  and `docs/astrbot-bridge-v1.md`.
- `animemo_base_url` is now an HTTPS origin with optional port only. URL
  credentials, non-root paths, queries, fragments, invalid ports, whitespace,
  and control characters fail closed.
- Contract tests prove that no TLS verification bypass exists and invalid
  service URLs are not reflected by command or diagnostics status.

No durable user data, identity, backup, migration, credential recovery, or
release identity contract changed.
