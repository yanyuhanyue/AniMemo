## Findings and fixes

### P4-001 — non-canonical credential key accepted

`durability.managed_config` used permissive URL-safe Base64 decoding. A key
with trailing invalid characters could pass configuration parsing and fail
later at the credential runtime boundary. Parsing now uses strict alphabet
validation and requires canonical re-encoding equality.

### P4-002 — partial target writes could be reported as complete

`durability.resource_budget.bounded_copy` counted source bytes but ignored the
return value of `BinaryIO.write`. A short write could therefore produce a
truncated target while reporting the expected byte count. The canonical copy
path now writes every chunk completely and rejects zero, negative, non-integer,
boolean, or over-reported write progress with `TARGET_WRITE_INCOMPLETE`.
