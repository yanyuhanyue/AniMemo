# 札记默认版式（2026-10-09）

用户已选定此前的融合版，并确认手机留白。现在直接打开 `/memory` 或 `/memory#notes` 即使用这一版，无需试用参数。关联作品的 `/memory?anime_id=<id>#notes` 使用相同版式。

`1.4.0-alpha.2` 在这一版式上新增可选的[札记主题](themes.md)，修改纸色、字体和限定留白，不恢复原来的候选布局或试用切换器。下面记录的是默认版式收敛当时的验收；最新容器与主题结果见[验收记录](verification.md)。

## 已完成的收敛

- 删除番剧影评、纸本札记、旧版风格三个候选方案，以及原默认札记列表、版式选择状态与切换入口。
- `NoteDesignPreview.tsx` / `note-design-preview.css` 收敛为 `NoteList.tsx` / `notes.css`；正式代码不再读取 `notes_ui`。旧试用链接仍能打开记忆库，其参数不再影响显示。
- 阅读、编辑窗口以及作品详情中的札记编辑入口采用同一套纸页配色。共享的瞬间画廊、收藏小册和图片管理布局继续保留。
- 桌面使用连续纸页、宋体标题与日期页边；已有海报显示在日期和珍藏下方。手机使用左侧 64 px 海报、右侧作品标签与日期/珍藏，卡片左右留白与海报文字间距均为 24 px。
- 保留蓝色内容标签、灰色可见范围标记和金色珍藏标记。作品名和正文分层显示，正文仍为主要内容。

札记数据、保存、分享、修订和剧透保护复用原有逻辑。本次没有 API、数据库迁移或生产依赖改动。关联作品按当前页去重批量读取，封面复用原私有接口；无封面或读取失败时不显示空相框。未知日期、仅年份等精度保持原意，不推断观看事实。
