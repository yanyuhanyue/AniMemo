# 1.1 实施与验收

范围依据 [当前更新路线](refactor-next-steps.md)，源码版本 `1.1.0-rc.1`。本次落实 1.1 的代码和操作入口；未将后续记忆功能、个人插件授权或市场提前并入。

| 范围 | 实施内容 |
| --- | --- |
| 诊断 | Node/Docker/Compose、空间、目录权限、配置、操作状态、数据库、Web/Worker 健康与监听检查；输出不包含凭据 |
| 配置 | `configure` 默认只预览，`--apply` 才更改；端口占用提前拒绝；原子配置写入，启动失败恢复原配置；保留停机状态 |
| 中断恢复 | 安装、恢复、备份、配置、更新、回滚使用同一私有操作日志；未完成操作拒绝被其他修改命令覆盖 |
| 备份与迁移 | v3 快照记录版本/源码/迁移/扩展/媒体；只读恢复计划；恢复后比较实际数据库清单；原数据和失败副本保留 |
| 密钥转移 | age 加密所有备份成员；错误身份、密文损坏或不完整快照拒绝；解密失败删除本次临时明文目录 |
| 发行 | 单一版本入口、二进制与 OCI 元数据、单次构建、固定摘要；官方安装入口验证仓库/工作流/tag/提交/归档证明 |
| 时间成本 | 复用实例/Worker/插件验收；VM 与 25 分钟负载不进入默认或发行依赖链 |

本地验证已通过：一次完整 Go/PostgreSQL/race 回归、12 组实例生命周期检查、5 组 Worker/扩展检查及恢复/回滚中断定向验证；所有随机探针均清理。现有验收站已升级且保留原 6 条展示数据。

可执行命令见 [实例操作](instance-operations.md) 和 [发行说明](release.md)。验证结果、镜像身份和限制以 [验收记录](verification.md) 为准。

远端签发与发布仍需真实完成。当前云端没有可用的 GitHub CLI 发行授权，签名服务网络也未完整开放；本地候选明确标记为开发产物，不伪装成官方发布。发行工作流和逐步接手说明已准备好，不以等待该外部步骤阻塞其他开发。
