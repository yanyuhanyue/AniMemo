# v1.4 私人手账与跨页面主题

本批源码为 `1.4.0-alpha.4`，接续 [札记模板首批](v1.4-theme-templates.md)。这是开发候选，尚未正式发布，也不表示完整 v1.4 已完成。

## 已实现

- 官方「星笺展架」1.1.0 同时提供札记展卡、手账卡片/列表和作品详情概览。管理员启用一次，用户分别在「札记外观」「手账外观」选择，预览取消不保存；默认界面继续可用。
- 手账主题可以重排海报、标题、评分、私密标记、标签和短评；详情主题安排概览。观看足迹、资料/分享、封面管理、编辑及危险确认由核心维护。批量管理使用默认布局。
- 相同标识、版本与内容重复上传不产生安装副本；组合主题的资源只存一份，多用户使用只增加选择记录。新版本供管理员显式切换，不自动替换启用版本。
- 后台显示各版本及合计的模块/资源逻辑大小，并可确认清理历史版本。当前使用版本和当前镜像随附基线受保护；清理不会改变正在使用的版本、用户记录或个人选择。移除后保留少量不可变版本摘要，不能用不同内容冒用曾安装的版本号。

## 实现边界与成本

新增宿主 API 5、`theme.journal` 与迁移 025，复用既有模板校验、Shadow DOM、个人选择、资源接口、插件安装和实例备份。没有新增生产依赖、前端脚本权限、主题专用数据库或构建服务。转换协议和 TXT 1.1.3 不随此批主题变化重新设计。

旧 API 3 token 和 API 4 札记模板继续支持；迁移保留原札记偏好。正常更新保留主题选择；克隆恢复清除两类选择并停用扩展，重新审核启用。包资源及清理后的身份摘要均在数据库备份内。

后台数字不包含数据库索引、清单、Docker 镜像及备份。数据库清理首先释放可复用空间，不保证物理文件马上缩小。当前版本没有自动淘汰历史包，也没有宣称跨不同包去重。

应用源码 `0fc1b60cd03f119c5f20d354ce19a87d1591d3b1`，候选镜像 `sha256:3ef1afaf698271218de3d8ba8b52a7f417ee2e40326de5fbd3959d3615d8034d`。完整浏览器与实际容器升级/恢复通过，既有验收站数据摘要核对一致；详见 [验收记录](verification.md)。

## 本地接手

源码、主题契约与测试入口见 [主题作者文档](themes.md)、[插件边界](plugins.md)、[验收记录](verification.md)。Linux Docker 是当前验证环境；Windows 使用 Docker Desktop 的 Linux 容器方式。仍不要求 VM 或 25 分钟负载作为开发前置。

```sh
node tooling/release.mjs load --directory .local/output/release-v14-alpha4 --development
npm run instance -- update --name local-review --image sha256:3ef1afaf698271218de3d8ba8b52a7f417ee2e40326de5fbd3959d3615d8034d
npm run instance -- status --name local-review
```

上述命令消费随交接包提供的候选归档。将 `local-review` 换为自己的实例名；新实例按 [实例操作](instance-operations.md) 初始化。不要用空 `.local` 覆盖既有配置。管理员把星笺展架切到 1.1.0 后，各用户自行选择手账外观；已有札记偏好继续跟随该包。
