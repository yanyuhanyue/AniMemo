# v1.4 第二批：可安装的札记模板

2026-10-09，源码版本 `1.4.0-alpha.3`。完成主题开发安排的前两批：协议/范围边界和札记模板试点。完整 v1.4 及全站主题仍在开发，不是正式发布。

## 交付内容

- 默认纸页保留；「樱色信笺」继续可选。新增「星笺展架」1.0.0，以双列展卡、作品海报和独立阅读侧栏验证另一种结构。
- 主题包携带标准 HTML 槽模板、CSS、图片、字体和许可文本。后台安装启用后，用户在「札记 → 札记外观」预览并应用；网站无需为不同主题重新编译。
- 宿主提供实际内容、读取权限和交互。主题样式隔离在其内容区域；编辑、保存、删除、剧透展开和后台始终由核心控制。剧透正文和附件只在主动展开后挂载。
- API 4 增加模板能力，保留 API 3 token 主题和 API 1–2 转换器。迁移 024 保存资源；正常升级保留选择，完整克隆恢复停用扩展并清除个人选择。
- 转换协议、主题类型和包清单分离。TXT 示例改为只依赖转换协议，重编译版本递增至 1.1.3；旧启用版本继续保留。

[主题契约](themes.md) 给出作者文件、槽名称、资源限制、各作用范围及后续全站策略。两个新增 Go 依赖用于解析标准 HTML/CSS；没有增加前端框架、主题脚本运行时或外部资源服务。

## 已完成的源码验证

静态检查、Go 单元和 18 项 Node 检查通过。真实 PostgreSQL 覆盖安装/启停、包身份冲突、主题选择、资源认证及摘要、损坏隔离、升级预检和旧转换流程。

真实浏览器安装过一份不同名称、不同模板的主题包，页面直接显示包内新结构，证实核心不按主题名称硬编码。新模板预览、字体/图片加载、列表/阅读、剧透、编辑、停用回退及手机布局通过，6 次 axe 无检出；默认纸页 3 次和 token 主题 5 次回归无检出，均无页面异常。自动检查不等于所有第三方主题或浏览器已获认证。

最终镜像的 6 组容器验收和 6 次主题浏览器扫描通过；验收实例已更新，13 张原内容/账号表的摘要保持一致，doctor PASS。详细范围和证据见 [验收记录](verification.md)。云端回环端口仍为 18082，本轮未建立公网入口。
