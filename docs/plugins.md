# 插件第一阶段：受限文件转换与版本化合同

截至 2026-10-07，已实现管理员本地包安装、显式启用 / 停用、历史版本切换、TXT 示例插件、用户预览确认导入，以及实例升级兼容检查。本阶段不是完整插件市场，也不兼容原项目 Python / JavaScript 插件。

## 为什么先做文件转换

原项目 `docs/architecture-debt-closure-report-20260812.md` 将非可序列化 SDK 边界列为尚未解决的例外：插件接触 Django / DRF request、QuerySet、事务和宿主路径，隔离运行时迁移会牵动宿主和插件。新实现只交换 JSON，不传数据库连接、认证对象、Go 指针、事务或 HTTP 请求。核心手账模块不导入插件运行时，插件不参与数据库事务中的回调。

文件转换是一个已有真实需求且可以完整约束权限的扩展点。插件接收用户主动选择的文件名和 UTF-8 文本，返回标准 JSON / CSV 导入文件。API 将结果交给现有 `journal.NewImport`：验证、预览、同名去重、确认、并发检查、私密写入和事务回滚继续归属手账模块。未安装插件也可以使用全部核心手账功能。

## 当前运行边界

- 使用固定版本 `github.com/tetratelabs/wazero v1.12.0` 的解释器执行 WASI Preview 1 模块；无需 C 库、Docker socket 或额外生产语言。
- WebAssembly 沙箱嵌入 Go 应用，不是独立进程或容器。未提供宿主业务函数、文件挂载、环境变量、数据库、密钥或网络 socket。仅有 stdin / stdout / stderr 数据通道。
- 每次实例化全新模块：线性内存最多 128 MiB；运行含加载最多 5 秒；输入最多 2 MiB；stdout 最多 8 MiB，实际返回导入文件最多 4 MiB；stderr 最多 4 KiB。每个 API 实例最多同时进行 2 个插件安装校验 / 转换。
- 时间到或请求取消关闭执行实例。插件陷阱、错误、超量输出不写手账；stderr / 原文件内容不会进入服务端日志。插件返回的简短错误仅显示给发起转换的用户。
- 线性内存上限不是整个宿主进程 RSS 上限，解释器 / JSON / 模块加载也占内存；这不是针对恶意发布者的独立 OS 资源隔离承诺。仍要求管理员先审核来源和代码。进一步开放第三方市场前应增加独立 worker 的 OS 配额与故障隔离，不改变 JSON 业务合同。
- 不提供持久插件 KV、文件、独立数据迁移、任意 UI 脚本、后台任务、网络代理、宿主事件或通用手账读写权限。这些能力不能通过在清单里增加名称获得。

## 唯一协议定义与兼容规则

`server/pkg/pluginproto/protocol.go` 是包清单和 stdin / stdout 消息的类型定义，示例插件直接消费它，不导入 `server/internal`。HTTP 管理接口仍以 `contracts/openapi.json` 为源。`tooling/check-layout.mjs` 阻止 SDK / 示例插件依赖宿主内部模块，也阻止手账模块依赖插件运行时。

包格式是一个 JSON 对象，包含 `manifest` 和 base64 `module`。包最多 12 MiB，模块最多 8 MiB；不解压归档、不写宿主插件目录，避免归档路径和符号链接问题。当前清单：

| 字段 | 规则 |
| --- | --- |
| `schema` / `protocol` | 均为 1；未知版本拒绝 |
| `slug` | 1–48 个小写字母、数字或连字符，以字母开始 |
| `version` | 三段非负整数 `major.minor.patch`，每段最多 6 位、无多余前导零 |
| `host_api_min` / `host_api_max` | 包含当前宿主扩展 API 版本 1；不是应用产品版本或 Go 版本 |
| `capabilities` | 必须且只能为 `["import.convert"]` |
| `module_sha256` | 模块真实字节摘要；安装时校验 |

同一 `slug + version` 内容不可改变，重复上传相同包是无操作，不会启用或切换版本。包身份摘要使用 Go 序列化的 Manifest（其中含模块摘要）；摘要证明一致性，不证明发布者身份或审核来源。未知字段、未知能力、额外 JSON 对象和无效模块拒绝。

输入为 `{"protocol":1,"filename":"2026记录.txt","text":"…"}`。输出为 `{"protocol":1,"format":"json","data":"标准 animemo.journal/v1 JSON 文本"}`，或 `format:"csv"`，失败输出 `{"protocol":1,"error":"简短错误"}`。输出仍经过核心导入校验，不能指定目标账号或绕过私密默认值。

`protocol` 和 `host_api_*` 是兼容契约，不随应用每次发布递增。未来破坏性变化引入新协议；旧协议是否继续支持必须明确决策并有消费者回归。当前严格拒绝未知字段，不承诺低版本静默接收未来字段；新字段 / 能力必须匹配声明的支持范围。不能直接把内部结构修改包装成不变的 SDK 版本。

## 权限撤销与状态语义

安装、启用、停用、版本切换均重新校验事务内管理员身份，记录审计；启停携带 `revision`，并发修改只允许一个成功。上传不自动启用，新版本上传不替换当前版本。

普通登录用户只能看到已启用版本，不能读取 WASM 包内容，也不能安装或切换插件。选择文件并执行一次转换，就是本次文件读取的明确授权；不存在长期用户授权或后台读取。

运行前检查启用状态，执行后重新核对部署 revision。期间停用或切换会丢弃该次结果；最多运行到 5 秒限制，不承诺管理按钮立刻终止 CPU 执行。已完成转换生成的导入预览归用户所有，停用插件后仍可由用户确认或取消；此时插件已经不再执行。

每个实例最多保留 32 个已安装版本、合计 256 MiB 模块。历史包保留用于回退；当前没有卸载 / 清理 UI，不应直接删数据库行绕过不可变身份规则。

## TXT 观看记录插件

构建与打包（Windows PowerShell 和 Linux 均从项目根目录执行）：

```sh
npm run plugin:example
```

Go 通过 `GOOS=wasip1 GOARCH=wasm` 构建，产物位于 `.local/output/watch-history-text.animemo-plugin`。管理员打开 `/admin` → 插件 → 选择插件包 → 核对清单并安装 → 启用。普通用户进入“导入与备份” → 选择转换器与文本 → 解析并生成预览 → 核对名称、日期、话数、刷次和笔记 → 确认导入。

支持 UTF-8（含 BOM）TXT。文件名包含年份，例如 `2026观看记录.txt`：

```text
10月1日
首刷 夏目友人帐 第1-3集
10月2日
二刷 夏目友人帐 第1集 -- 重温
```

也支持每行制表符分隔的 `YYYY-MM-DD、标题、1-3、刷次、笔记`，前 3 列必填。`共12集` 表示记录第 1–12 话，不推断作品已经完结。默认首刷；同文件中相同标题、日期、话数、刷次去重，重复记录保留第一次的笔记。单次最多 500 部、2000 条记录。缺失 / 模糊日期或话数会报告具体行，不猜测后写入。

这是旧版 TXT 导入的基础子集：**暂不支持 GBK、多文件、日期区间、模糊匹配、Bangumi 补全、逐项选择，以及给已有同名番剧追加观看事件**。现有同名番剧整体跳过，界面会提示。生成的普通导入任务可刷新续办，确认后所有新条目为私密。核心预览新增最多 100 条观看记录明细，也适用于 JSON / ZIP 导入。

## 升级、备份与回滚

安装包原始模块、清单、摘要、全部版本与启用状态都存 PostgreSQL，包含在原有实例备份内。当前插件无外部状态，因此镜像 + 数据库 + 实例密钥快照覆盖本阶段完整插件状态。

`animemo plugins-check` 是只读命令，在迁移前检查所有已启用包的协议、能力、支持范围、摘要、模块结构、WASI 导入函数及其签名、无参数无返回值的 `_start` 入口；旧数据库没有插件表时允许继续，停用包不阻止恢复。普通 `serve` 启动也先检查，再运行数据库迁移。

`tooling/instance.mjs update` 在数据库副本还原后，通过候选镜像执行 `plugins-check`，成功才切换配置并启动迁移；失败恢复原镜像和原数据库。不自动停用不兼容插件，也不静默升级插件包。插件间版本切换与实例升级是独立操作：前者只是切换已安装版本，后者把全部插件状态一起快照。回滚后新写入的救援备份行为保持原有规则。

这不保证插件输出的业务正确性；新版本仍需使用真实样例执行消费者测试。将来引入插件外部存储、KV 迁移或网络写操作前，必须补齐对应备份 / 补偿 / 恢复策略，不能继续声称只恢复数据库就覆盖全部状态。

## 验证入口

```sh
npm run test:plugins
npm run verify
npm run plugin:example
```

定向测试会构建真实 Go WASI 模块，验证文件 / 网络 / 环境隔离、超时 / 取消 / 内存 / 输出限制、错误保密、包身份、协议拒绝、未知 WASI 函数 / 入口签名拒绝、权限、并发切换、真实 PostgreSQL 导入与升级预检查。生成文件均在 `.local`。

构建生产镜像后，设置 `ANIMEMO_CANDIDATE_IMAGE`，执行 `npm run test:plugin-instance`。可设置 `ANIMEMO_PREVIOUS_IMAGE` 验证从无插件旧版迁移，设置 `ANIMEMO_INCOMPATIBLE_IMAGE` 验证真实不兼容候选镜像恢复。所有镜像必须已在本机存在，测试创建随机 `probe-*` 实例并清理自己的容器和卷。

可选浏览器验收设置 `ANIMEMO_PLUGIN_BROWSER=1`。Playwright 测试工具安装在 `.local/tools/browser`（当前使用 1.62.1），通过 `ANIMEMO_PLAYWRIGHT` 指定其 `index.mjs`，通过 `ANIMEMO_BROWSER` 指定 Chromium 可执行文件；不配置后者则使用 Playwright 自己已安装的 Chromium。云端使用 `/usr/bin/chromium`。浏览器和容器报告分别写入 `.local/output/browser/plugin-report.json` 和 `.local/output/plugin-smoke.json`。结果见 `verification.md`。
