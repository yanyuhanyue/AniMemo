# Memory Core 领域合同 v1

本合同冻结职责和数据权属，HTTP DTO 以 `contracts/openapi.json` 为准。合同变更先评估个人记忆、导出和扩展消费者，再版本化；不要求提前建立所有未来功能的数据库表。

| 概念 | 身份与归属 | 当前落地 / 后续约束 |
| --- | --- | --- |
| Anime | 本地 UUID，当前按 owner 隔离 | 已落地 `anime_resources`；provider ID 是附属映射。未来共享资料目录只能新增公共投影，不能换掉用户已引用的本地 ID |
| Character / Episode | 独立本地身份，外部身份可替换 | 已落地 characters / episodes、角色别名/作品关联、Episode 多来源映射及归并重定向；拆分保留原引用。扩展不能直接建立核心表 |
| UserAnimeEntry | owner + Anime，编辑时带 version | 当前 `entries`；列表筛选和当前评分来自它，不把一次编辑视为完整历史 |
| WatchEvent | owner、Anime、观看范围、刷次、有效时间精度、记录时间 | 当前 `watch_records` + revision。日期精度与系统 recorded_at 分离；更正/撤回追加修订；未知日期禁止伪装成精确日 |
| EpisodeScope / ProgressAssertion | 用户表达的观看范围与进度依据 | 已落地本地集数目录与固定 UUID 集合的 progress_assertions；支持主线/全部/自定义和精确/近似/追平，不合成观看事件 |
| Rating / Status / Notes revision | owner 的历史事实 | 已落地 `memory_revisions`；有意义修改同事务留存。公开投影不附带私人历史 |
| MemoryNote / Anchor | owner 的正文，引用本地资源和可选观看上下文 | 已落地独立 memory_notes；Anchor 是笔记内定位；支持时间精度、图片、可见性、剧透/珍藏。观看上下文失效保留正文与引用 |
| 媒体 | Core 持有引用、配额、可见性及备份责任 | PostgreSQL/R2 是后端选择；扩展不能以私有外部 URL 成为用户唯一原件。封面迁移通过 mediastore；私人原件由 journal 独立预留/校验/缩略图/配额/清理，当前存在 PostgreSQL |
| 专栏 / 公开分享 | 可撤回的公开投影 | 已有独立 DTO；公开改动不改变私人事实，私人记录不能被搜索或导出给其他账号 |
| Extension | publisher + package digest + installation ID | 已落地最小身份；只拥有扩展执行状态与包。不能拥有唯一一份核心 WatchEvent、评分、笔记或媒体原件 |

## 最小记录与未知事实

`entries.status=recorded` 表达“记得看过，细节未记”，与 `completed` 分开。只填作品名可以创建私密记录，观看话数保持 0（尚无已记录话数），不插入 WatchEvent，不计作完成或精确观看。UI 对未填写话数显示“具体话数未记”，不显示 0% 完成任务。

MemoryNote 可仅关联 Anime，使用未知日期并留下自由文字；角色、Episode、WatchEvent 与 Anchor 均非前置条件。只有用户明确填写的集数范围才进入观看记录；撤回最后一条精确记录后保留作品和独立回忆。已有历史状态不在迁移时改写。

新建与 Bangumi 资料搜索默认 recorded；资料源只补充作品信息，不证明观看完成。Bangumi 没有对应的模糊状态，因此这类记录不会被猜成“看完/在看”推送；用户需要写回时明确选择可映射状态。

## 事务与事件

`journal` 拥有记忆事务。API 传入已认证 owner，外部同步通过 `journal` 入口；扩展返回 JSON，API 交给核心导入，不能拿 SQL、事务或 Go/React 对象。

条目/观看修订与 `core_outbox` 同事务写入；记忆库修订写入 `library_revisions`。成就使用 PostgreSQL 持久待处理标记，消费者幂等；检索/记忆串直接投影核心表。Outbox 是至少一次调度，当前内部投影使用事件 ID 去重，不能据此声称外部网络写入恰好一次。未来每种外部副作用必须单独规定幂等键、结果未知时的核对和补偿方式。

## 导出与恢复

`animemo.journal/v3` 包含当前条目、观看、身份与修订，以及独立记忆/图片原件、角色/集数、收藏、年度冻结内容、成就历史。无新增记忆库内容时输出本项目 v2。ZIP 另外含封面原件；实例快照含账号、密钥、任务、扩展包与全部媒体。分享凭证不进入个人导出。范围见 [1.3 交付](v1.3-delivery.md)。

完整记忆包恢复到空手账；目标 owner 和资源/条目/观看/修订 UUID 重新生成，内部引用随之重映射，原有修订的 recorded_at 保留。恢复动作不合成另一套“刚刚观看”的历史。超限显式报错，不静默截断。

当前每份直接导出上限：5000 条目、20000 观看记录、10000 作品身份、50000 修订。详情页展示最近 100 条修订；完整历史仍在数据库和导出中。日期范围过滤当前按保存的日历锚点比较，月份/年份筛选的区间相交语义尚未提供；用户不应把局部日期范围统计解释为精确发生时间。

移出条目会清掉当前列表、观看投影及封面，保留私有作品身份和文字修订；账号删除清空该账号全部私有数据。独立记忆附件有原件及删除墓碑；已主动删除的字节不从旧年度投影复活。封面的逐修订原件归档和一键还原某条历史 UI 未交付，完整恢复使用个人包或实例快照。
