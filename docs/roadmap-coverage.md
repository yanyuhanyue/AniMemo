核对日期：2026-10-09。执行路线仍为 [Linux 开发与渐进交付](refactor-next-steps.md)。本表解释需求去向，不另立开发或发布门禁。

## 结论与口径

**核对前的新路线没有完整覆盖原方案。** 它保留了部署、基础手账和受限扩展，但把角色、年度记忆、成就等明确目标降为远期候选，漏写了 PWA、主题插件、三种展示模式及一些记忆完整性要求。本次补回主要功能族与关键数据/权限约束，同时保留 Linux 基线、全新项目和按改动验证规则。

**当前实现也不等于原路线产品终态。** 1.3 候选已新增记忆正文、角色、瞬间、年度册与轻量 Universe；后台沿用 Calm Utility。v1.4 首批已加入浅色札记声明式主题，第三方包可按同一协议安装；暗色主题、任意前端执行和语义插槽仍未开放。范围与证据见 [1.3 交付](v1.3-delivery.md) 与 [1.4 首批交付](v1.4-delivery.md)。

用户后续明确定位优先：本项目记录看过的番剧，不承担追番排期或提醒。RC2 将角色/集数/成就收为可选整理工具，简化主入口；这是交互层级调整，不删除已有记忆或恢复旧路线门禁。

对照来源为用户上传的三份文件：《更新路线.md》《路线改.txt》《AniMemo_更新路线_v10_整合第一方官方扩展策略.md》。下面以 v10 的章节和行号定位主要要求；它是需求参考，不是当前执行指令。早期文件的相同功能合并记录；版本冲突按当前路线重新排期，例如早期 v1.2.1 的成就现在分批进入 v1.3 系列。附件不复制为第二份有效路线。

“已有基础”只表示相应代码/流程存在，不表示该整行原要求已全部验收。“计划”表示尚未交付；“范围受限”表示不能据此宣称完整支持。本表按功能族追踪，不声称逐句验证了旧文件全部协议细节，也不提供虚假的新路线完成百分比。原项目 **52/62** 的冻结统计见 [功能对照](feature-parity.md)，与本表不同。

### 六步真实页面审查

审查使用真实实例 API 和合成验收账号，无 API mock。按登录 → 手账 → 详情 → 设置 → 后台插件 → 手机手账顺序，保留修改前后截图和机器扫描记录。交互过程涉及敏感登录字段，截图不包含填写后的密码。

1. **登录：需修正后可用。** 保留插画与票根的品牌表达；修正辅助文字、切换按钮和贴纸的对比度。未覆盖实际邮件收件及 OAuth 外部站点。
2. **手账：部分符合。** 主要操作明确，空封面仍可识别作品；减少横幅和统计的视觉占用。当前样本缺少真实封面，不能据此完成“海报主导”验收。
3. **详情：部分符合。** 进度、观看历史与修订可查看；修正徽标/日期/说明色。记忆正文、关联角色、截图组的信息架构待对应核心模型实现。
4. **设置：功能可用，结构待完善。** 有个人资料、配色与账号安全入口；长弹窗需要更清晰的分组。当前账号颜色偏好不是主题扩展。
5. **后台插件：基本符合本页的 Calm Utility 方向。** 独立导航、权限和状态清晰。本次无严重自动扫描发现；这个结果不代表所有后台状态均已测试。
6. **手机手账：已修正主要导航问题。** 三个原入口复用为底栏，没有复制业务路由；统计保持紧凑，保留安全区。后续公开页和复杂筛选面板仍需统一移动体验。

截图、前后 axe 输出、视口和交互结果位于 `.local/output/browser/roadmap-audit/`；可读报告为该目录的 `report.html`。最终执行范围与结果见 [验收记录](verification.md) 的本次 UI/路线复核条目。报告只评价观察到的页面和状态，不把代码推断写成已观察交互。

## 有意调整，不属于功能遗漏

- **用户明确取消/改为可选：** 旧版数据、API、插件 ABI、安装目录兼容；VM 和固定约 25 分钟负载不再强制。不能以后借“符合旧路线”重新加入这些门禁。
- **目标保留、实现简化：** Linux/Docker 上直接开发验证；Go 单体与独立 Worker；复用现有快照、更新恢复、可信产物与简明回执。无需先造 Windows Secret Broker、VM Campaign/租约控制器、Python→Go 双轨 Host Agent 或三层交接回执平台。
- **有实际需求再定：** 组织迁移、旧固定安装域名、额外发行镜像源、多 OS/多架构和市场分发。它们不能成为写个人记忆之前的前置工程。
- **排期变化须显式：** 角色/年度/成就/PWA/主题等现在有明确去向；首次生产可以缩小范围，但不能把尚未实现的目标标记完成或无声删掉。

当前继续 v1.4：在声明式札记主题之后，以一个真实展示插槽验证扩展接口，再推进个人授权和最小 Bridge。PWA、AI、市场与正式签发的未完成状态保持明确，不因新增主题被记作完成。
